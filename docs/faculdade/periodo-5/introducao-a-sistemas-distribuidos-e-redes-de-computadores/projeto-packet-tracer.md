# Projeto Packet Tracer

[**Projeto de Reestruturação da Rede dos Laboratórios do CIn-UFPE**](projeto-packet-tracer/untitled.md)

## Sobre este guia

Este material foi desenvolvido para auxiliar na realização de todas as entregas do projeto utilizando o **Cisco Packet Tracer**. Cada seção abaixo contém explicações detalhadas dos conceitos teóricos e instruções práticas passo a passo.

---

## Como utilizar este guia

1. **Leia sequencialmente**: as entregas são interdependentes — siga a ordem apresentada.
2. **Pratique no Packet Tracer**: implemente cada conceito conforme avança.
3. **Documente seu trabalho**: capture telas e anote suas decisões de design.
4. **Teste constantemente**: verifique a conectividade após cada configuração.

## Pré-requisitos

Antes de começar, certifique-se de:

- Ter o **Cisco Packet Tracer** instalado e funcionando.
- Conhecer seu **número de grupo**, para obter o bloco IP correto.
- Ter acesso aos documentos do projeto.
